## Project Description
The Reading List Tracker is a console-based Python program that
helps users keep track of books and articles they read.

Users can add books, record reading time, choose a reading status,
view their reading list, and see a summary of their reading activity.

## Features
- Add a book or article
- Record reading time in minutes
- Track Finished and In Progress statuses
- View all saved books
- Calculate total reading time
- Count finished and in-progress books
- Find the book with the most reading time
- Validate user input

## Project Files
- main.py: Displays the menu and controls the program.
- tracker.py: Contains the program functions.
- data.py: Stores information in parallel lists.
- README.md: Contains project documentation.
- issue_tracking.csv: Tracks project tasks and issues.

## How to Run
1. Open the project in VS Code or GitHub Codespaces.
2. Open the terminal.
3. Run the command:

   python3 main.py

## Topics Used
- Console input and output
- Variables, strings, and numbers
- Functions
- Lists and parallel lists
- Loops and conditional logic
- GitHub version control

## Data Storage
Book information is stored in parallel lists while the program
is running. The information is not permanently saved after
the program exits.
